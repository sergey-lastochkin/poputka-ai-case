## Единые условия

Пилот — в одном городе: продукты, бытовые товары и кафе. Лекарства не входят в MVP. Наличие, состав, цену и интервал согласуют до оплаты.

База: рейс 300 ₽ / три заказа = 100 ₽ курьеру на заказ; доставка 99 ₽; комиссия магазина 10%; чек 1 200 ₽; не более 15% бесплатных доставок по адресным акциям. Общей бесплатной первой доставки нет.

М1 — разработка без продаж. М2 — пилот и половина месяца продаж. Массовый маркетинг с М3 — только при подтверждённом пилоте, среднем рейсе от трёх заказов и курьере не дороже 100 ₽/заказ.

Retention-7 для пилота: повторный завершённый оплаченный заказ в дни 1–7 после первого, только для когорт с полными семью днями наблюдения. Промо-повторы показываются отдельно. Удержание 75% месяц к месяцу — самостоятельная гипотеза.

## Базовый прогноз

| Показатель | Значение |
| --- | ---: |
| Выручка сервиса с заказа | 204,15 ₽ |
| Маржа после переменных расходов | 69,05 ₽ |
| LTV / CAC | 4,14 |
| Заказы за М1–М6 | около 5 936 |
| Выручка сервиса за М1–М6 | около 1,21 млн ₽ |
| Первый положительный месяц | М4 |
| Остаток денег на конец М6 | около 470 тыс. ₽ |
| Накопленный результат выходит в ноль | М7 |

Это прогнозные допущения, а не результаты пилота. Результат до налогов и возвратов; зарплата команды в модели равна нулю.

В Excel выберите 1, 2 или 3 в B2 листа «Допущения». Сводка, экономика заказа, помесячные результаты и бюджет пересчитываются для выбранного сценария. В пессимистичном сценарии массовый маркетинг после пилота остановлен; сохраняются расходы на разработку, поддержку курьеров и сервер.
